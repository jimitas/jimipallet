# じみパレット - 地味に助かる学習コンテンツ

## 概要
jimitas.com は、小学生向けのインタラクティブな算数学習ツールを提供するWebアプリケーションです。楽しく効率的に算数の基礎から応用まで学習できます。

## 主な機能

### 学習コンテンツ
- **さんすうノート** - 自由に書き込める算数ノート
- **すうずぶろっく** - 数の概念を視覚的に学習
- **とけい** - 時計の読み方を練習
- **100までのけいさん** - 基本的な計算練習
- **大きなかず** - 大きな数の理解
- **たし算のひっ算** - たし算の筆算練習
- **ひき算のひっ算** - ひき算の筆算練習
- **九九のれんしゅう** - 九九の暗記と練習
- **かけ算の筆算(1)** - かけ算の基本的な筆算
- **かけ算の筆算(2)** - かけ算の応用筆算

### インタラクティブ機能
- ドラッグ＆ドロップによる直感的な操作
- 手書き入力対応
- 音声フィードバック
- カラーパレットでの色分け学習
- スクリーンショット機能

## 技術スタック
